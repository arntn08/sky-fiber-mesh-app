RN410 live pairing · read-only

Not paired

One-time local pairing for testing: SKY MESH remains your management interface while the authenticated RN410 tab supplies read-only device data. No mother modem or internet connection is required. Your router password and session cookie are not sent to SKY MESH.

Keep both tabs open while monitoring. The script reads the RN410's device arrays and WAN status every 10 seconds and sends only that read-only data to this app tab. Close the router tab to stop the relay. Never paste passwords, cookies, or authorization headers into this app.

First, open the router page from this button. Log in if needed, then use the browser DevTools Console and select the sky_iframe execution context before pasting the script.
